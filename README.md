# Westbound Optimizer 🌵

Optimization script for **Westbound**, focused on improving performance and reducing unnecessary visual effects without adding gameplay advantages or exploit functions.

## 📌 Features

- Performance-focused optimizations
- Reduction of unnecessary visual effects
- Lightweight configuration
- Designed to improve overall game performance
- No functions intended to provide gameplay advantages

## ⚙️ Optimization

The script focuses exclusively on client-side optimization, aiming to reduce unnecessary graphical workload and improve performance on devices with limited resources.

## 📱 Compatibility

Designed for use with **Westbound**.

Performance improvements may vary depending on the device and game settings.

## ⚠️ Disclaimer

This project is provided for educational and optimization purposes.

The script does not intentionally include features designed to give players an unfair gameplay advantage.
